## 📚 Repository Structure

- **Phase 01 — Data Types:** Types, casting, enums, structures, and system functions.
- **Phase 02 — Arrays & Collections:** Arrays, queues, associative arrays, and array methods.
- **Phases 03–12 — Advanced SystemVerilog:** Functions, tasks, packages, OOP, randomization, constraints, assertions, coverage, and advanced verification concepts.
- **SV-149 — Multi-Language EDA:** SystemVerilog with Python, Perl, C/DPI-C, and Tcl.
- **Phase 13 — UVM:** Architecture, sequences, drivers, monitors, scoreboards, TLM, factory, register models, and protocol-based verification.

Each topic includes **concepts, runnable code, expected output, Vivado workflow, and GitHub notes**.

## 🎯 Why SystemVerilog & UVM?

- **SystemVerilog:** Describes digital hardware and provides powerful features for design and functional verification.
- **UVM:** Provides a reusable, scalable methodology for building structured, self-checking verification environments.
