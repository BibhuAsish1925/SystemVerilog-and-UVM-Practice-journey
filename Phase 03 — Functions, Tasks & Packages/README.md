
# Phase 3 — Functions, Tasks & Packages ✅

## Overview
This phase covers reusable code blocks and shared definitions in SystemVerilog. It introduces functions and tasks, argument passing, variable lifetime, and packages for organizing and reusing types, classes, and functions across a project.

## Topics Covered

### 1. Functions, Tasks and Reusability

| No. | Topic | Concepts Covered |
|---|---|---|
| SV-025 | Functions ✅ | Function declaration, arguments, return value |
| SV-026 | Tasks ✅ | Task declaration, timing controls |
| SV-027 | Function/Task Arguments ✅ | `input`, `output`, `inout`, `ref` |
| SV-028 | Lifetime ✅ | Automatic lifetime, static lifetime |
| SV-029 | Void Functions ✅ | `void` return type, `void'(expression)` |

### 2. Packages and Shared Definitions

| No. | Topic | Concepts Covered |
|---|---|---|
| SV-030 | Packages ✅ | `package`, `import`, scope resolution `::` |
| SV-031 | Package + Types + Classes ✅ | Typedefs, enums, classes, package functions |

## Key Learning Areas

- **Reusable code:** Create functions and tasks to organize repeated operations.
- **Argument passing:** Understand how `input`, `output`, `inout`, and `ref` affect data transfer.
- **Execution behavior:** Distinguish automatic and static lifetime and understand timing controls in tasks.
- **Return handling:** Use `void` functions and `void'(expression)` appropriately.
- **Code organization:** Use packages, imports, and scope resolution to share definitions.
- **Reusable definitions:** Group typedefs, enums, classes, and functions into packages.

## Practical Work

Each topic is practiced through runnable SystemVerilog examples and Vivado simulation to observe execution behavior, argument handling, and the reuse of package definitions.

## Learning Outcomes

After completing this phase, you should be able to:
- Write and call functions and tasks.
- Pass arguments using different directions and references.
- Explain static and automatic variable lifetime.
- Use void-returning operations appropriately.
- Organize shared types, classes, and functions in packages.

## Tools
- **Language:** SystemVerilog
- **Simulator:** AMD Vivado
- **Practice:** Runnable code examples, expected outputs, and GitHub learning notes
