
# Phase 4 — Object-Oriented SystemVerilog ✅

## Overview
This phase introduces object-oriented programming (OOP) in SystemVerilog. It covers classes and objects, constructors, inheritance, encapsulation, polymorphism, and object copying. These concepts help build reusable, modular, and maintainable verification components.

## Topics Covered

## Key Learning Areas

- **Class design:** Create classes, objects, properties, methods, and constructors.
- **Code reuse:** Extend existing classes and use `super` to access parent-class behavior.
- **Data protection:** Apply encapsulation and controlled property access.
- **Polymorphism:** Use parent-class handles and virtual methods for dynamic behavior.
- **Advanced class features:** Work with casting, virtual classes, static members, constants, and parameterized classes.
- **Object management:** Understand handle copying, shallow copying, deep copying, and cloning.

## Practical Work

Each topic is practiced through runnable SystemVerilog examples and Vivado simulation to observe class behavior, object relationships, method dispatch, and copying operations.

## Learning Outcomes

After completing this phase, you should be able to:
- Design and instantiate SystemVerilog classes.
- Apply inheritance, encapsulation, and polymorphism.
- Use virtual methods and class casting.
- Create reusable parameterized classes.
- Explain the differences between handle, shallow, and deep copying.

## Tools
