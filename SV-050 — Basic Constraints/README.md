# 050 — SV-050 — Basic Constraints

SystemVerilog constraints are used to **control the values generated by randomization**.

Constraints are declared inside a class using a `constraint` block.

### Constraint Syntax

```systemverilog
constraint data_range {
    data >= 10;
    data <= 50;
}
```

When `randomize()` is called, the simulator generates values that satisfy the constraint.

### Relational Constraints

Common relational operators used in constraints include:

| Operator | Meaning                  |
| -------- | ------------------------ |
| `==`     | Equal to                 |
| `!=`     | Not equal to             |
| `<`      | Less than                |
| `>`      | Greater than             |
| `<=`     | Less than or equal to    |
| `>=`     | Greater than or equal to |

For example:

```systemverilog
constraint address_range {
    address >= 100;
    address < 200;
}
```

This restricts `address` to values from `100` through `199`.

### Why it matters in verification

Constraints allow random stimulus to remain **legal and meaningful**. Instead of generating completely unrestricted values, the verification environment can define valid ranges and relationships for transactions.


**Key concepts:** `constraint` blocks, relational constraints, legal random values, constraint solver, constrained `randomize()`.
